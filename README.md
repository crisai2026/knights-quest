# Knight's Quest Saga

A browser-based adventure game with 12 minigames, dynamic weather, and challenging boss fights.

## How to Play

- **Arrow Keys**: Move
- **Space**: Jump
- **Shift**: Run
- **R**: Switch Weapon
- **F**: Attack
- **E**: Interact
- **W**: World Map

## Features

- 10 levels across different biomes
- 4 villagers × 3 minigames each (12 total)
- Dynamic beach tide with breath mechanic
- Jungle puddle piranhas
- Boss fights
- Coin collection & item crafting

Enjoy! 🎮
